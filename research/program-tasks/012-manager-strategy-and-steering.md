# 012: Give the manager an evidence-based overview and route decisions

Outcome: the manager can explain knowns/unknowns, compare approaches, commission
the next useful investigation and change direction after evidence or steering.
Use the real graph and chat tools from 008/010/011, not a second static agenda.

Implement a durable approach board with live/promising/parked/retired states,
prioritization reasons, evidence dependencies, objections, estimated cost,
discriminating observations and reopening conditions. Manager reasoning can be
model-based; validate recorded actions and references in ordinary code. Support
bounded scouting/literature and tooling assignments through the same worker path.

Capture the human's question, practical tradeoffs, notes, links, hunches and
accepted steering with provenance. An informal hunch remains an idea; an explicit
instruction changes the authorized direction/limits. Produce a concise cited
brief rather than asking the human to maintain a database or merge worker logs.

Done when:

- An initially broad question becomes at least two credible routes and one
  funded discriminator with rival explanations and outcome-dependent decisions.
  Fresh fits/physics/simulated collection remain available with targeted budgets,
  supported speedup and appropriate recording, not a hidden zero default.
- A meaningful negative result parks/retires an exhausted route with scope and
  reopening reasons; an unexpected result can promote an alternative. A tool
  failure does not reject a hypothesis. A cheap failed method does not erase
  a credible broader approach or manufacture scientific certainty.
- Withdrawing a supporting claim triggers review/reprioritization using graph
  traversal and surviving derivations; a second manager reconstructs the rationale.
- Steering changes the next allocation without rewriting earlier evidence or
  cancelling unrelated active work. Repeated inconclusive trials hit a recorded
  futility/retry limit and trigger reframing/parking instead of endless repeats.
- Worked cases using saved mixed/negative evidence demonstrate the manager's
  decisions and references. Deterministic fixtures test action/state validation;
  a prompt string containing the right words is not sufficient verification.

Deliver strategy behavior in the existing manager conversation. Do not require
an extra permanent strategist or a whole-corpus extraction job.
