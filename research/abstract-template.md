# Descriptive research title

Status: pending, in progress, complete, interrupted or blocked.

## Abstract

In 100–200 words, state the research question, what was actually tested, the
main measured result and its limitations. Short tool checks can use fewer words.
State when no experiments have been completed. A process exit code alone does
not establish that the research objective was achieved.

## Topics

Search terms such as autocalibration, HP3, candidate ranking, held-out sweeps,
identifiability, cable elasticity or compiler crashes. Use the actual topics.
