# Main repo integration review

The research worktree's 11-line change is supported against its baseline by E17/E18: both live jobs collected bit-identical datasets (180 length pairs and 2,590,397 physics steps); the warm run accepted 2.420 mm anchor RMSE versus 2.706 mm for the cold run. The warm result repeated in E14, while the cold result is a single run. This is credible evidence for a small gain on this simulated HP3, no-buildup case. It does not establish a general hardware or all-configurations improvement. The broader half-density claim is not supported: collecting at five points per subsweep plateaued around 3.8 mm, while thinning a standard collection can retain accuracy.

Main already contains the overlapping, additive approach in 294e24c8: each iteration adds one history-seeded fit candidate and keeps all cold candidates unchanged. The main checkout's separate session `2026-10-15-...-267d719f` reports a matched live A/B improving applied RMSE from 2.706 to 2.440 mm, with bit-identical cold fits. That approach has direct evidence on the newer code path and avoids replacing cold starts. The worktree patch seeds every ordinary run from the previous selected anchors; applying it on top would both duplicate the warm candidate and change cold-start diversity. The 2.420 mm result is only 0.020 mm below the existing 2.440 mm result in one warm run, so it does not justify that extra change. The code patch was therefore not cherry-picked.

The supplied regression_run.log reports mixed dataset-level changes: nine of eleven truth-error totals improve and two worsen; some iteration counts differ. Its aggregate is diagnostic only, not a clean general-performance claim. It is retained under evidence/ alongside the source report.
