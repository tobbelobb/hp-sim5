# HP5 direct: passive-axis sensor policy comparison

At the current 0.05 N compliant force the redundant low axis intermittently loses take-up tension (up to 1.2–3.4 mm biased range), while raising it to 0.3–1 N keeps it taut (≤0.09 mm) and adds a consistency constraint that mainly improves the weakest anchor direction; the gain is real but bias-sensitive, so production defaults should stay unchanged pending a production-fitter replay.
