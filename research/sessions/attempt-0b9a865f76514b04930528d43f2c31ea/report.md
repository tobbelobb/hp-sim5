## Frozen protocol and failed design

Both engine artifacts were built with the same Rust 1.99.1 release compiler, C bridge and no PGO. [Build metadata](evidence/native/old.node.json) and [current metadata](evidence/native/current.node.json) contain every native source hash, compiler configuration and binary hash. The old native SHA-256 is `98f4c408c637ed7d081a279d4ed048e3390722919c797b030a4fa5b591848742`; current is `66a8451bc1a42310e4dfae166288737e595f75bc1173c8f88e92163afb94a5d8`.

Fresh worlds use the stock HP3 scene and firmware, radii 30/30/30/30 mm, zero buildup, disabled layering, one 2 ms physics substep and native Rust. Firmware M666 readback confirms R30 and Q0. Collection uses speedup 25 and event recording. Current fitting and selection code are fixed, fast L-BFGS-B, 400 solver iterations, four restarts, maximum three active-learning iterations. Known geometry never selects measurements, seeds, thresholds or applied answers. No truth-assisted operational rule was added.

The fixed manual forces are low/mid/max 0.01/0.05/0.5 N and sensor force 1 N, with automatic force tuning disabled. These differ from stock automatic force tuning. Consequently these runs do not measure stock one-click accuracy or general current-autocal reliability. The first pair uses six points per direction; the second pair and corrected old attempt use the production default of 20. All settings match within each pair.

Initial allocation was 12 minutes, at most four fresh calibrations, two builds, at most three fits per attempt, 1,200,000 physics steps and 145 wall seconds per attempt, with eight seconds for cancellation cleanup and no retries. All four ended naturally before these limits. After detecting ABI masking, the assigning manager explicitly amended its own allocation to one additional 145-second corrected attempt and 15 minutes total; the authorization is preserved in the experiment ledger. The fifth attempt was the only extension. Synthetic torque checks are two 500-step worlds, not additional calibrations. Jobs ran sequentially.

The original `old` and `old20` labels mean old native artifact with current wrapper. The wrapper set ABI slot 12 to zero, disabling the old calculation before it reached the old engine. These two runs cannot serve as historical simulator baselines. Their exact equality to current is a useful mask diagnostic, not evidence that the historical simulator behaved identically. The corrected historical-wrapper run changes only the wrapper and native engine; current autocal/collector code and scene remain fixed. Temporary wrapper changes are restored after collection and are not production changes.

Run the committed summarizer after jobs finish.

No production code is proposed. Older substepping, rotor coupling and force-feedback changes need their own matched interventions; this session cannot attribute all current calibration error to any one of them.
