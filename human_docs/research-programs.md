# Research programs

Start with [research-program/README.md](../research-program/README.md). It describes
both entry points, stable investigation IDs, explicit resume, platform-owned parallel
researchers, optional physics worlds, fixed-evidence review, and storage.

```bash
./hp-sim5-research-program --question 'Your research question'
./hp-sim5-research-program --resume PROGRAM_ID
./hp-sim5-research-agent --codex --prompt 'Your independent investigation'
./hp-sim5-research-agent --resume INVESTIGATION_ID
```

Use the current T3 or hosted conversation as manager. The
[research-program skill](../.agents/skills/research-program/SKILL.md) describes how
to use platform agents. The [corpus skill](../.agents/skills/research-corpus/SKILL.md)
explains how findings accumulate into useful knowledge.
