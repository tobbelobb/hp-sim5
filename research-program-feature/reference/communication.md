# Communication settings

`--grill-me` enables a startup discussion. `--ask-questions` enables consequential
questions during work; `--ask-questions-along-the-way` is an alias. Both are off
by default and have `--no-...` forms. `--dont-ask` is the older alias for disabling
ongoing questions. Worker questions go to the manager through a small mailbox.

The flags are passed as data beside the canonical manager role instructions.
They do not load another manager prompt. Client settings enable the relevant
question tools when either flag is enabled.
